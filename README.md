# GifDisplay

![License: MIT](https://img.shields.io/badge/License-MIT-pink)

在 A Dance of Fire and Ice 内显示本地 GIF 动画，并可自由调整位置、缩放和透明度。

---

## 安装与使用

### 前置依赖

- [JALib](https://github.com/Jongye0l/JALib) 已作为 Mod 安装到游戏 `Mods` 目录
