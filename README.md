# GifDisplay

![License: MIT](https://img.shields.io/badge/License-MIT-pink)

在 A Dance of Fire and Ice 内显示本地图片，支持 png,jpg,webp,gif 格式，并可自由调整位置、缩放和透明度，并且能同时显示多张图片。

---
