# GifDisplay

![License: MIT](https://img.shields.io/badge/License-MIT-pink)

在 A Dance of Fire and Ice 内显示本地图片，支持 png,jpg,webp,gif 格式，并可自由调整位置、缩放和透明度，以及图片的显示模式，并且能同时显示多张图片，支持对每个图片实例进行单独的配置。

---

## 安装与使用

在 [Release](https://github.com/Skrepy0/GifDisplay/releases) 界面下载最新稳定版,并配合 [UnityModManguager](https://github.com/newman55/unity-mod-manager) 使用
