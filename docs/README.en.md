# GifDisplay

![License: MIT](https://img.shields.io/badge/License-MIT-pink)

Display local images inside *A Dance of Fire and Ice*, with support for PNG, JPG, JPEG, and GIF formats. Freely adjust position, scale, opacity, and display mode for each image. Multiple images can be shown simultaneously, and every image instance can be configured independently.

---

## Installation & Usage

Download the latest stable release from the [Releases](https://github.com/Skrepy0/GifDisplay/releases) page and install it with [UnityModManager](https://github.com/newman55/unity-mod-manager).
